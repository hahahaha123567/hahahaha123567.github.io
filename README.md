# hahahaha123567.github.io

个人博客源码，基于 Hexo。

博客地址：[https://hahahaha123567.github.io/](https://hahahaha123567.github.io/)

## 目录和文件

```text
.
├── _config.yml                 # Hexo 站点配置
├── source/
│   ├── _posts/                 # 博客文章
│   ├── favorite/               # 收藏文章索引
│   ├── image/                  # 文章和站点图片
│   ├── link/                   # 友情链接页面
│   └── search/                 # 搜索页面
├── themes/
│   └── cactus/                 # 博客主题
├── scaffolds/                  # 新文章和页面模板
├── .github/workflows/          # 自动构建与发布配置
├── package.json                # 项目依赖和常用脚本
├── package-lock.json           # 依赖版本锁定文件
└── public/                     # Hexo 生成的静态文件
```
